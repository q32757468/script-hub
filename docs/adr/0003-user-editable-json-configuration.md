# 使用用户可直接编辑的 JSON 作为配置来源

用户明确要求全部任务配置保存为 JSON，并将任务配置放在用户目录下以便直接修改，因此使用用户主目录下 `.script-hub/config.json` 保存带版本号的应用设置、任务、变量配置及文件引用，不采用数据库或仅由界面管理的私有配置。导入文件、运行状态与历史独立保存；软件通过完整替换、有效备份及版本检查保护可读性和恢复能力。

全部任务停止后才能显式重新加载配置，重新加载不触发任务自动启动。软件保存前检查外部修改，发生冲突时由用户决定加载磁盘版本或覆盖，覆盖前备份磁盘版本；无效配置不得替换当前有效配置。这一规则优先保护用户手动修改的内容，首版不提供自动合并或实时加载。
