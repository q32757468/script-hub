# 一个任务使用一种命令编辑方式

任务同时面向直接填写完整命令的用户和希望通过组成项编辑命令的用户，因此支持完整命令与组合编辑两种方式，每个任务选择其一。两种方式最终都生成一条完整命令字符串执行，不在生成后将其解析为“程序与参数数组”再分别调用。组合编辑中的有序组成项是编辑辅助，不表达执行步骤；不要求两种方式自动转换。该决定影响任务配置模型与执行边界，首版不扩展为多步骤编排。

组合编辑仅区分程序、文件引用与文本。文本由用户自由输入，可以包含一个或多个参数，不再细分单个参数与参数片段。组成项按顺序以空格连接，软件处理文件引用的路径引号，自由文本与输入变量替换结果保留为命令文本，由用户控制参数引号，并在运行前展示最终命令预览。

用户自行填写执行命令，首版不增加执行终端选择设置，也未接受将固定 `cmd.exe` 作为产品要求的建议。底层命令执行机制须满足上述完整命令语义，不能据此改成只接受单个程序和参数列表的产品模型。
