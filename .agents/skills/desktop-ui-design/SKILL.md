# Desktop UI Design

This skill is primarily intended for desktop UI. Read [DESIGN.md](DESIGN.md) in this directory before creating or updating the project's interface styles. Use it as the reference for colors, typography, layout, spacing, shapes, depth, and components, while respecting the user's requested changes.

Keep design details in `DESIGN.md` as a separate file rather than duplicating them here.
